# Références et Ressources Académiques

Cette section regroupe les outils et identifiants essentiels pour la gestion bibliographique et la rédaction scientifique.

## 1. Identifiants Majeurs (Métadonnées)
*Ces identifiants permettent à Zotero et BibLaTeX de récupérer automatiquement les informations de vos sources.*

- **[DOI (Digital Object Identifier)](https://www.doi.org/)** : L'empreinte numérique unique pour les articles scientifiques.
- **[ISBN (International Standard Book Number)](https://www.isbn-international.org/)** : Identifiant unique pour les livres.
- **[arXiv ID](https://arxiv.org/)** : Identifiant pour les prépublications (physique, maths, informatique).
- **[ISSN (International Standard Serial Number)](https://www.issn.org/)** : Identifiant pour les revues périodiques.
- **[PubMed ID (PMID)](https://pubmed.ncbi.nlm.nih.gov/)** : Identifiant de référence en médecine et biologie.

## 2. Profils Chercheurs & Identité
- **[ORCID](https://orcid.org/)** : Identifiant unique et pérenne pour les auteurs de recherche (indispensable).
- **[Google Scholar Profile](https://scholar.google.com/intl/en/scholar/citations.html)** : Pour suivre ses citations et son impact.
- **[Web of Science ResearcherID](https://www.webofscience.com/wos/author/search)** : (Anciennement Publons) Gère les publications et le peer-review.
- **[Scopus Author ID](https://www.scopus.com/freelookup/form/author.uri)** : Profil d'auteur généré par la base de données Scopus.

## 3. Logiciels de Gestion Références (RMS)
- **[Zotero](https://www.zotero.org/)** : **Recommandé.** Open-source, excellent avec l'extension *Better BibTeX* pour LaTeX.
- **[JabRef](https://www.jabref.org/)** : Logiciel de gestion natif au format BibTeX/BibLaTeX.
- **[Mendeley](https://www.mendeley.com/)** : Gestion de PDF et réseau social académique.
- **[Paperpile](https://paperpile.com/)** : Solution basée sur le cloud, très efficace pour Google Docs et LaTeX.
- **[Citavi](https://www.citavi.com/)** : Gestion de références et de connaissances (Windows uniquement).
- **[EndNote](https://endnote.com/)** : Standard industriel (souvent payant) pour les domaines non-LaTeX.

## 4. Moteurs de Recherche & Bases de Données
- **[CrossRef](https://www.crossref.org/)** : Source principale pour transformer un DOI en entrée BibTeX.
- **[BASE (Bielefeld Academic Search Engine)](https://www.base-search.net/)** : L'un des moteurs les plus puissants pour les ressources en accès ouvert.
- **[WorldCat](https://www.worldcat.org/)** : Catalogue mondial des bibliothèques (idéal pour les ISBN).
- **[CORE (COnnecting REpositories)](https://core.ac.uk/)** : Agrégateur mondial de papiers en Open Access.
- **[JSTOR](https://www.jstor.org/)** : Bibliothèque numérique de journaux académiques et de livres.
- **[Zenodo](https://zenodo.org/)** : Dépôt de données et de logiciels (CERN), permet de citer du code.

## 5. Outils LaTeX & Flux de Travail
- **[LaTeX Project](https://www.latex-project.org/)** : Site officiel du projet LaTeX.
- **[BibTeX.org](https://www.bibtex.org/)** : Documentation sur le format standard BibTeX.
- **[EndNote Click (ex-Kopernio)](https://endnote.com/product-details/endnote-click/)** : Extension pour trouver les versions PDF gratuites/légales des articles.
- **[DataCite](https://datacite.org/)** : Pour la création et la gestion des DOIs de données de recherche.

## 6. Archives et Outils Obsolètes (Legacy)
- **CiteULike** (Archivé)
- **Colwiz** (Devenu Wizdom.ai)
- **RefMe / Cite This For Me** (Outils simplifiés pour le web)
