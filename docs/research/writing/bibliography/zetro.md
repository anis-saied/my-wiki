# Zetro

:::info
Citer vos sources est une question de crédibilité, de droit et de service rendu à votre lecteur.
:::

Zetro est un outil de gestion de références bibliographiques.

## installation

### linux

Sur Ubuntu:

```bash
curl -sL https://raw.githubusercontent.com/retorquere/zotero-deb/master/install.sh | sudo bash
sudo apt update
sudo apt install zotero
```

## Extensions

- for google chrome: [Zotero Connector](https://www.zotero.org/download/)
- for latex: [Better BibTeX](https://retorque.re/zotero-better-bibtex/installation/)
  - **zotero-better-bibtex** used with **bibtex/biber** to export citations in latex documents.
