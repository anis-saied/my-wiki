# 📚 Sources de Ressources Académiques

Ce répertoire liste les meilleures plateformes pour enrichir votre bibliothèque Zotero.

---

## 🌍 Moteurs de Recherche Universels
*La porte d'entrée pour trouver tout type de documents scientifiques.*

| Source | Type de contenu | Accès | Particularité |
| :--- | :--- | :--- | :--- |
| 🔍 **[Google Scholar](https://scholar.google.com/)** | Articles, Thèses, Livres | **Gratuit** | Le plus complet ; permet de voir qui a cité un article. |
| 🛡️ **[BASE](https://www.base-search.net/)** | Ressources académiques | **Gratuit** | Très rigoureux, évite les sites non-scientifiques. |
| 🤖 **[Semantic Scholar](https://www.semanticscholar.org/)** | Articles (IA) | **Gratuit** | Analyse le texte pour extraire les conclusions clés. |
| 📊 **[Dimensions](https://app.dimensions.ai/discover/publication)** | Publications & Brevets | **Freemium** | Interface moderne avec analyse de l'impact des sources. |

---

## 📖 Livres et Manuels (E-books)
*Pour trouver des ouvrages de référence pour votre manuel.*

| Source | Type de contenu | Accès | Particularité |
| :--- | :--- | :--- | :--- |
| 🏛️ **[Open Library](https://openlibrary.org/)** | Livres numérisés | **Gratuit** | Bibliothèque mondiale ; permet d'emprunter des e-books. |
| 💻 **[O'Reilly / Safari](https://www.oreilly.com/)** | Informatique & Tech | **Payant** | Incontournable pour les manuels de programmation/IT. |
| 📜 **[Project Gutenberg](https://www.gutenberg.org/)** | Littérature classique | **Gratuit** | Idéal pour les sources historiques (domaine public). |
| 🏢 **[SpringerLink](https://link.springer.com/)** | Sciences & Technique | **Payant*** | Livres de très haute qualité (souvent offert par les universités). |
| 📚 **[Google Books](https://books.google.com/)** | Tous types | **Variable** | Utile pour consulter des extraits avant achat. |

---

## 📄 Articles de Revues & Pre-prints
*Pour les recherches les plus récentes.*

| Source | Type de contenu | Accès | Particularité |
| :--- | :--- | :--- | :--- |
| 🚀 **[arXiv](https://arxiv.org/)** | Physique, CS, Maths | **Gratuit** | Standard pour l'informatique et les mathématiques. |
| 🇫🇷 **[HAL Open Science](https://hal.science/)** | Recherche pluridisciplinaire | **Gratuit** | La plateforme de référence pour la recherche française. |
| 🧪 **[ScienceDirect](https://www.sciencedirect.com/)** | Science & Médecine | **Payant*** | Base de données géante d'Elsevier. |
| 💎 **[DOAJ](https://doaj.org/)** | Revues Open Access | **Gratuit** | Répertorie uniquement des revues 100% gratuites et certifiées. |
| 🎭 **[JSTOR](https://www.jstor.org/)** | Sciences Humaines | **Freemium** | Très riche pour l'histoire, les arts et la sociologie. |

## 🎓 Thèses, Données et Rapports
*Pour trouver des travaux approfondis et des statistiques.*

| Source | Type de contenu | Accès | Particularité |
| :--- | :--- | :--- | :--- |
| 🎓 **[Theses.fr](https://www.theses.fr/)** | Thèses françaises | **Gratuit** | Indispensable pour trouver des thèses soutenues en France. |
| ☁️ **[Zenodo](https://zenodo.org/)** | Données & Logiciels | **Gratuit** | Permet de trouver des jeux de données et du code source. |
| 📈 **[Statista](https://www.statista.com/)** | Statistiques & Marché | **Payant** | Le leader pour les chiffres et graphiques prêts à l'emploi. |
| 🇪🇺 **[DART-Europe](https://www.dart-europe.org/)** | Thèses Européennes | **Gratuit** | Accès aux portails de thèses de 28 pays. |

---

## 💡 Astuces pour votre manuel
> **(*) Accès Institutionnel :** Si vous avez des identifiants universitaires, utilisez-les via un VPN ou un proxy. Beaucoup de ressources affichées comme "Payantes" sont en réalité déjà payées par votre établissement.
>
> **L'icône Zotero :** Une fois sur l'une de ces pages, cliquez sur l'icône Zotero de votre navigateur pour enregistrer instantanément la source et le PDF dans votre base de données.
