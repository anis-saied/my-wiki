# DDL

DDL = CREATE / ALTER / DROP

## Online DDL

👉 Online DDL permet de modifier une table sans bloquer (ou presque) les lectures/écritures.

## Lock Type

Ça définit ce qui est bloqué pendant l’ALTER.
