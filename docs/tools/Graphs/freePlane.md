
# FreePlane

## Overview
FreePlane is a free, open-source mind mapping and knowledge management software. It's a fork of Freeplane that enables users to organize thoughts, ideas, and information visually.

## Key Features
- **Mind Mapping**: Create hierarchical visual maps of concepts and ideas
- **Outlining**: Organize information in structured outlines
- **Rich Formatting**: Support for text styling, colors, and icons
- **Attachments**: Link files, URLs, and images to nodes
- **Scripting**: Extensible via Groovy scripting for automation
- **Export Options**: Save as PDF, PNG, HTML, and other formats

## Use Cases
- Project planning and brainstorming
- Knowledge documentation
- Study notes and learning
- Process visualization
- Information architecture
