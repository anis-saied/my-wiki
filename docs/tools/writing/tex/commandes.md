# Commandes simples

## Espaces

### Espace vertical

```tex
ligne 1
\medskip
ligne 2
```
`\medskip` sert à créer un petit espace vertical entre les paragraphes ou sections.
Cela ajoute un espace un peu plus grand qu’un simple retour à la ligne, mais plus petit qu’un `\bigskip`.

C’est pratique pour aérer le texte sans utiliser de paragraphes complets (`\par`).
