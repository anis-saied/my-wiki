
# Zensical

## Overview
Zensical is a lightweight, minimalist web framework designed for building fast and efficient static websites with a focus on simplicity and performance.

- deploy on GitHub Pages: [https://zensical.org/docs/publish-your-site/#github-pages](https://zensical.org/docs/publish-your-site/#github-pages)

## Key Features
- **Minimal overhead** - Stripped-down architecture for maximum speed
- **Static generation** - Pre-rendered HTML for optimal performance
- **Simple configuration** - Easy setup and deployment
- **Developer-friendly** - Intuitive API and documentation

## Getting Started
```bash
npm install zensical
# or
yarn add zensical
```

## Configuration
Basic setup example:
```javascript
const zensical = require('zensical');

zensical.init({
    input: './src',
    output: './dist',
    theme: 'default'
});
```
