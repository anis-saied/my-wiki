
# What is Sphinx?

Sphinx is a powerful documentation generator originally created for Python documentation. It converts reStructuredText (RST) or Markdown source files into various output formats like HTML, PDF, and ePub.

## Documentation

- Official documentation: [https://www.sphinx-doc.org/en/master/](https://www.sphinx-doc.org/en/master/)

## Deployment

- deploy on read the docs: [https://docs.readthedocs.com/platform/stable/intro/sphinx.html](https://docs.readthedocs.com/platform/stable/intro/sphinx.html)

## Key Features

- **Multiple Output Formats**: Generate HTML, PDF, ePub, and more
- **Search Capability**: Built-in full-text search for HTML documentation
- **Theming**: Extensible theming system for customization
- **Cross-referencing**: Automatic linking between documents
- **API Documentation**: Excellent for documenting code with docstrings
- **Extensions**: Powerful plugin system for extended functionality

## Common Use Cases

- Software documentation
- Project guides and tutorials
- API references
- Technical writing

## Getting Started

```bash
pip install sphinx
sphinx-quickstart docs
```
