
# DevOps Learning Roadmap

## Parcours DevSecOps : 
- le learning path complet: [https://blog.stephane-robert.info/docs/](https://blog.stephane-robert.info/docs/)

## Beginner
- **Linux Fundamentals**: Commands, file system, permissions
- **Version Control**: Git basics, branching, merging
- **Scripting**: Bash/Python basics

## Intermediate
- **Containerization**: Docker, images, containers
- **Orchestration**: Kubernetes basics
- **CI/CD**: Jenkins, GitLab CI, GitHub Actions
- **Infrastructure as Code**: Terraform, Ansible

## Advanced
- **Cloud Platforms**: AWS, Azure, GCP
- **Monitoring & Logging**: Prometheus, ELK Stack, Grafana
- **Advanced K8s**: Helm, operators, security
- **DevOps Culture**: Agile practices, collaboration

## Tools & Technologies
- Container registries (Docker Hub, ECR)
- Configuration management
- Service mesh (Istio)
- Infrastructure automation
- Cost optimization
