# Trello - kanban

## Project managment
- Project : n features
- 1 feature : n tasks
    - each task have : name, description and priority
    - order tasks by priorities into the backlog
        


## kanban

### backlog
Le backlog dans Kanban est une liste de tâches ou d'éléments à faire, généralement triés par priorité.
