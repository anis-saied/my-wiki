# Badges

Voici quelques sites populaires où tu peux trouver des templates ou générateurs de badges modernes, sobres ou personnalisables :

## Shields.io

Le standard open-source pour générer des badges personnalisés (SVG).
Large choix de styles (flat, plastic, social, etc.).
Génération dynamique avec texte, couleur, icône.

## Badgen.net

Alternative à Shields.io, très rapide, badges simples et modernes.
Personnalisation couleur, texte, icône.

## Badge Generator (simpleicons.org)

Permet de créer des badges sobres à partir de la bibliothèque d’icônes simpleicons.

## CSS Badge Generator (cssbud.com)

Générateur de badges CSS personnalisables.
Tu peux voir le rendu et récupérer le code CSS/HTML.

## Bootstrap Badges

De nombreux exemples de badges sobres prêts à l’emploi avec Bootstrap.
Pratique si tu utilises Bootstrap dans ton projet.

## Badge.design

Générateur de badges SVG moderne, personnalisable, simple d’utilisation.

## Heroicons Badges

Si tu utilises Tailwind CSS, tu trouveras des templates de badges très sobres et modernes.

## Astuce :

Pour t’inspirer du style des badges de grands sites (GitHub, Amazon, etc.), examine leur CSS avec les outils de développement du navigateur et adapte-le à tes besoins !

Si tu veux des badges “design system” pro (Material, Ant Design, etc.) :

- Material UI Badge
- Ant Design Badge
