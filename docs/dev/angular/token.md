# token

- une représentation symbolique d’une valeur, d’un droit ou d’une information.
- C’est une entité qu’on utilise à la place de la donnée réelle pour plus de sécurité, de simplicité ou de praticité.
- un jeton (token) remplace la donnée réelle.
- Sens général : représentation symbolique, preuve, jeton.
## Domaines d’utilisation et exemples

### Informatique (authentification & sécurité)

- **Access Token** (JWT, OAuth, etc.) : une chaîne de caractères signée qui représente l’identité d’un utilisateur et ses droits.
- Exemple : après un login, le serveur te donne un token que tu utilises pour prouver ton identité.
  - CSRF Token : un jeton unique utilisé pour sécuriser les formulaires et éviter des attaques.
- Ici, "token" = preuve d’authentification.

### Programmation

- **Token lexical** : en compilation, un "token" est une unité syntaxique comme un mot-clé (if, while), un identifiant (`userName`), un symbole (`{`, `;`).
- Ici, "token" = élément de langage.
