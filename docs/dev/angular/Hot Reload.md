# Hot Reload

Pourquoi ton app ne se rafraîchit pas automatiquement

Normalement :

`ng serve` ou `ng serve --open` → Hot Reload actif ==> à chaque sauvegarde → recompilation + refresh auto


Tu lances Angular sans ng serve , par exemple `npm start`
