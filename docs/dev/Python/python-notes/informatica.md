## Informatique

- paradigme : modèle de programmation, détermine la manière de penser, de réléchir d'un développeur, et par conséquent la manière de modéliser des problèmatiques (détermine la manière de formulation des algorithmes et l'organisation de code source)
- Notes: Paradigme objet n'est pas mieux que le paradigme impératif, il est simplement plus adapté dans certains contextes, mais il est également, par opposition, moins adapté à d'autres contextes.

## Grammaire

- un  grammaire : ensemble de mots et de règles de productions (relations entre les mots)
- un mot : ensemble ordonné de symboles
- un symbole: 
  - appartient à un ensemble fini  nommé alphabet
  - symboles terminaux et non terminaux

## Paradigmes

- Python : 
  - est conçue demanière à permettre 
    - nativement d'utiliser plusieurs paradigmes
    - utiliser d'autres paradigmes via l'utilisation des bibliothèques tierces
  - Permet une programmation impérative
  - Permet les deux styles de programmation : par objet et par prototype
  - permet la programmation par composants
  - permet la programmation evenémentielle
  - est un langage mutli-paradigmes

### Paradigme Objet

Exemples : Java, Eiffel, Smalltalk, C++

Deux grandes variantes

1. Paradigme Objet par Classes (Progammation par objet)

   - Exemple : C++, Java
   - Consiste en l'écriture des classes : permet d'avoir des instances

2. Paradigme Objet par Prototype (Programmation par prototype)

   - Exemples: JavaScript
   - Consiste à définir le nom de la classe et ajouter des méthodes
     - pas d'instanciation : Les objets ne sont que des conteneurs de méthodes statiques

3. Progrmmation orientée composant

   - Structurer le code en briques réutilisables (pas de duplication de code)

4. Progrmmation orientée evenement

   

### Paradigme Fonctionnel

Exemples : Lisp, Haskell, Caml, Erlang, Scheme

- consiste à centrer la réflexion sur les données et non pas sur les algorithmes
- un programme purement fonctionnel : s'il n'autorise pas la programmation impérative (ex: Erlang)

### Paradigme Logique

Exemples : Prolog

- Les données sont plus importantes que les algorithmes
- Une application = **graphe**  de **règles logiques** applicables à des données par le biais d'un **moteur d'inférence**
- se rapproche de la théorie de graphe
- il est la base de la **programmation par contrainte**
- il est utilisé pour l'intelligence artificielle
- Python propose des modes de Programmation logique
  - PyPy
  - PyKE(Python Knowledge Engine) : permet d'utiliser le paradigme logique au sein de CPython

##### Programmation par contrainte

- dérivée de la programmation logique
- python-contrainte: module Python, permet de déclarer un problème, insérer des contraintes et demander des solutions

### Paradigme par aspect

Exemples : AspectJ

- Modules Python pour la programmation orientée aspect : aop, aspyct, aspects, Sprint Python



### Programmation concurrente

- conçue pour permettre la réalisation de plusieurs tâches simultanément (tâches concurrentes)
- concurrent : package Python permet la programmation concurrente

### Programmation par contrat

- permet de poser des préconditions et des postconditions
- pycontract : module Python
