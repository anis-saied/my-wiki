Organisation des événements : 

permet aux membres de se rencontrer et continuer à apprendre et à s'améliorer constamment, découvrir aux autres les projets sur lesquels on s'est impliqué



Organisation des sprints:

permet de réunir des développeurs sue quelques jours ou quelques heures autour du développement d'un projet libre écrit en python 

- le logiciel libre concerné évolue
- le sprint est encadré par des personnes très investies et particulièrement expérimentées 
- Les participants sont soumis à des règles strictes concernant l'organisation des ces développements qui sont nécessaires pour travailler en équipe
- Les participants moins expérimentés apprennent beaucoup de ce genre d'évènement
  -  sur Python
  - sur les techniques de collaboration
  - sur la gestion de projets
  - des méthodes agiles
