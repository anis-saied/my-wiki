# Voies de développement

## Programmation

On peut utiliser python pour la programmation :

- la programmation système

- l'informatique embarquée

- La programmation concurrente

- La programmation parallèle
  - **stacklessPython**: implémentation spécifique pour la programmation parallèle

- La programmation de serveurs web

- La programmation des sites web

- La programmation de serveur pour client lourd

- programmation pour des clients lourds

- application client/serveur

- programmation temps réel

- programmation des pilotes de matériels  : piloter matériel avec Python
  - capacité bas niveau et facilité d'utilisation des protocoles 

- conception interfaces utilisateurs

## Comunication

On peut utiliser python pour  :

- communiquer avec Base de données
- communiquer avec des annuaires LDAP
- utiliser des services web
- s'interfacer avec des programmes issus de différents technologies
- manipuler des fichiers : CVS, XML, PDF, documents de bureautique, images, vidéos, son
- communiquer avec des péréphiriques
- piloter des tables traçantes, des imprimantes 3D, des servomoteurs
- gestion de protocole XML-RPC

## le monde de la recherche

Python est largement utilisé dans le monde de la recherche

- doctorants et chercheurs : réalisent des projet => nécessitent la création d'outils informatique => faire de développement => utilise Python => le langage idéal pour travailler sur leurs données
- dispose de suffisamment de bibliothèques pour répondre à tout type de problématiques
- permet de faire de calcul scientifique
- générer des graphes
- faire du calcul distribué
- est un langage proche des mathématiques
- python est une altérnative de Mathematica et Matlab
