## Python interpreter
Python interpreter consists of several components, and two crucial components are the Python compiler and the Python Virtual Machine (PVM).

Python interprter (implemented in C for CPython)
the interpretation and execution of bytecode are handled by the Python interpreter, 

### Python compiler (compile to bytecode)
- the Python compiler, is part of the interpreter.
- the Python compiler compile (translate) python source code to (abstract) bytecode
- the byte code is a set of instructions
- This compilation step happens before the program is executed and results in a .pyc (compiled Python) file.
- When you run the Python script, the Python interpreter checks if there is a corresponding .pyc file (compiled bytecode),(Python generates a .pyc file for caching) for the source file and if the source file has been modified since the last compilation.
- If the .pyc file is missing or outdated, the Python interpreter compiles the source code into bytecode and creates or updates the .pyc file.
- the bytecode is generated in a temporary directory (usually the __pycache__ directory) or alongside the source file.
- to explicitly see or control the generation of .pyc files, you can use the py_compile module or the -m py_compile command. 
For example: `python -m py_compile your_script.py` This will generate a .pyc file in the __pycache__ directory. 
### Python Virtual Machine (PVM)
- The PVM interprets (line by line) and executes the bytecode generated by the Python compiler.
- The PVM is responsible for translating the bytecode into machine code, during runtime. 
- The machine code generated is specific to the platform and is not typically exposed or viewed by the developer.
- machine code isexecuted by the computer's hardware.
## the bytecode 
- the bytecode is specific to the Python implementation (CPython, Jython, IronPython, etc.), 
- the bytecode is not meant to be written or modified by developers directly.
