## Python implementations

*CPython* is the reference implementation of Python

- Jython : 
  - Java implementation, 
  - generate bytecode readable by the Java virtual machine
  - have all the Java library into the Python code, 
  - can load and use a jar file
  - interpreteur Python construit au dessus de la machine virtuelle Java
  - permet 
    - de lire des programmes python par la machine virtuelle Java
    - à un programme Python d'utiliser des bibliothèques de Java (ex: SWT)
  - 

IronPython

- PyPy:
  - implémentation de Python écrite en Python
  - pypy.org
  - utilise le compilateur à la volée JIT
