# reStructuredText

## Overview
reStructuredText (reST) is a lightweight markup language designed for readability and ease of use in documentation, particularly within the Python community.

## Key Features
- **Readability**: Plain text format that's easy to read in source form
- **Extensibility**: Supports custom directives and roles
- **Documentation**: Primary markup for Sphinx documentation generator
- **Semantic**: Emphasis on semantic meaning over visual presentation

## Common Syntax
- **Headers**: Using over/underlines with symbols (`=`, `-`, `~`, etc.)
- **Inline Markup**: `*emphasis*`, `**strong**`, `` `code` ``
- **Lists**: Numbered, bulleted, and definition lists
- **Code Blocks**: Using `::` or `.. code-block::` directive
- **Links**: Explicit and implicit hyperlink references

## Use Cases
- Python project documentation
- Sphinx-based documentation systems
- Technical writing with semantic markup
- API documentation
