# AsciiDoc

## Overview

AsciiDoc is a lightweight markup language designed for writing technical documentation. It provides a simple, readable syntax that converts to multiple output formats including HTML, PDF, and DocBook.

## links
- official documentation: [https://asciidoc.org/](https://asciidoc.org/)
- [Asciidoctor Documentation Site](https://docs.asciidoctor.org/)
- [AsciiDoc on wikipedia](https://en.wikipedia.org/wiki/AsciiDoc)
- [AsciiDoc : le guide complet](https://blog.stephane-robert.info/docs/developper/autres-langages/asciidoc/)

## Key Features

- **Plain text format** - Easy to read and version control
- **Rich formatting** - Supports headings, lists, tables, code blocks, and more
- **Flexible output** - Converts to HTML, PDF, DocBook, and other formats
- **Extensible** - Customizable macros and attributes
- **Well-suited for documentation** - Ideal for technical manuals and guides

## Basic Syntax

### Headings
```
= Document Title
== Section
=== Subsection
```

### Lists
```
* Bullet point
** Nested point

. Numbered item
.. Nested item
```

### Code Blocks
```
[source,python]
----
def hello():
    print("Hello, World!")
----
```

## Tools & Ecosystem

- **Asciidoctor** - Modern toolchain for AsciiDoc processing
- **AsciiDoc Python** - Original AsciiDoc implementation
- **Browser support** - Viewer extensions available for browsers

## Use Cases

- Technical documentation
- Software manuals
- API documentation
- Blog posts and articles
